## Burnside Project

Open infrastructure for governed analytics, PostgreSQL intelligence, and AI-ready data products.

We believe organizations should own their data, govern AI access, and build analytics without warehouse lock-in.

### Products

#### pg-cdc

The security boundary between production PostgreSQL databases and AI agents.

Streams PostgreSQL WAL changes into typed, compacted Parquet files in cloud storage. Creates a physical air gap between production systems and analytics consumers.

#### pg-warehouse

Local-first analytics development.

Pull governed datasets into local compute, build transformations using a medallion architecture, and publish reusable data products without requiring a cloud data warehouse.

#### wire-drop

Secure governed data exchange.

Share datasets, features, and analytical artifacts between organizations without exposing production systems.

#### ai-dial-pad

Publish governed data products as conversational endpoints.

Turn governed datasets into AI-ready MCP endpoints that can be safely queried by Claude, ChatGPT Enterprise, and other AI tools.
